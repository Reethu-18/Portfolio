RITHVIK'S PERSONAL PORTFOLIO — INTERACTIVE EDITION

Files
- index.html: portfolio structure and content
- style.css: dark editorial styling, responsive layout, themes, transitions and animations
- script.js: mobile navigation, active section links, scroll progress, reveal animations, skill-bar animation, subtle pointer tilt, theme toggle, copy-email helper and contact form validation

How to run
1. Extract this ZIP archive.
2. Open rithvik_portfolio/index.html in a modern browser.
3. Internet is only needed for the Google Fonts and Bootstrap CDN resources; the page layout and interactions are implemented locally.

Interactive features
- Floating navigation with mobile menu and active-section highlight
- Scroll progress indicator and back-to-top button
- Scroll-triggered reveal animations and animated skill bars
- Subtle desktop pointer glow and 3D project-card tilt
- Dark/light theme toggle
- Copy-email button with feedback toast
- Contact form validation that opens the visitor's email app with a prepared message
- Reduced-motion preferences respected

Notes
The contact form does not send or store data on a server. It opens the visitor's configured email application. The portfolio contains the personal details provided by Rithvik; project links can be added when live demos are available.
